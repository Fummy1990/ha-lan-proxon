# Brand images

Eigenes, generisches Symbol (Haus + Lüfterrad), keine Herstellermarke.

Die PNG-Dateien werden unter `custom_components/proxon_fwt/brand/` mit der
Integration ausgeliefert. Ein separater Pull Request bei `home-assistant/brands`
ist dafür nicht erforderlich.

- `icon.png` (256×256) und `icon@2x.png` (512×512)
- `logo.png` / `logo@2x.png` (hier identisch mit dem Icon)

Dieser Ordner enthält die Originaldateien einschließlich der SVG-Quelle.

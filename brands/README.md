# Icon für home-assistant/brands

Eigenes, generisches Symbol (Haus + Lüfterrad), keine Herstellermarke.

Damit Home Assistant das Symbol anzeigt, muss es im Repository
[home-assistant/brands](https://github.com/home-assistant/brands) unter
`custom_integrations/proxon_fwt/` eingereicht werden (Pull Request):

- `icon.png` (256×256) und `icon@2x.png` (512×512)
- `logo.png` / `logo@2x.png` (hier identisch mit dem Icon)
